# PRIME — Team walkthrough

## Review sequence

1. Open Dashboard in each product. Check the product switcher, quick actions and key priorities.
2. Expand lower dashboard sections. Confirm the content matches PIM/RIM/TIM.
3. Inspect primary navigation, then All modules. Look for duplicate or unclear labels.
4. Open a record in Requests / Sales / Issue & return. Check the detail view.
5. Create a demo draft. Confirm validation and success feedback.
6. In RIM, open Point of sale, add items, change quantities and complete a **demo** sale.
7. In TIM, attempt to issue the blocked torque wrench. Confirm the restriction.
8. In PIM, review a pending approval and reject it with a reason.
9. Test mobile menu, bottom navigation, tables as cards, Scan, and Chat.
10. Report problems in GitHub Issues. Include edition, page, device width, expected result and actual result.

## Central feedback

For comments visible to the whole team, use:
https://github.com/BankMoney24/Prime-UI/issues

## Important privacy boundary

Use fictional data only when testing the public GitHub Pages website. Do not paste real customer records, company secrets, credentials or production data into the public repository or GitHub Issues.
